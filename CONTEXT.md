# wit03.xyz

A personal site for wit03, framed as a dive: the hero is the surface and each section is a deeper stop. It also hosts the journey of wit03's side projects.

## Language

### The dive

**Surface**:
The first screen: the hero sitting on the visitor's live sky, with the waterline along its bottom edge.
_Avoid_: Hero section, landing

**Section**:
A stop on the dive below the surface, shown at a fixed depth in metres.
_Avoid_: Block, panel

### Projects

**Project**:
One of wit03's side projects, documented on its own page as a single running note that grows over time.
_Avoid_: Post, case study, portfolio item

**Projects overview**:
The page listing every Project; the homepage's first Section previews it as a carousel.
_Avoid_: Portfolio, projects index

**Vault**:
wit03's private Obsidian vault, the source of truth for Project notes. Only notes marked as published ever reach the site.
_Avoid_: CMS, content folder
